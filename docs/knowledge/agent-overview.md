## 可以做的事

智能助手只能通过服务端注册的工具访问数据，工具都调用系统现有的业务服务，自带权限和数据范围校验。

- 查询：用户、用户详情及其角色、角色、部门、登录日志、登录失败统计、账号锁定状态、操作日志摘要、在线会话。
- 操作：启用或停用账号、解除账号锁定、强制下线。这三类写操作只会生成审批卡片，用户点击"批准"后服务端才执行。
- 解答系统规则、权限配置和操作步骤：回答依据知识库文档，涉及具体用户、角色、权限或在线状态时还要用查询工具确认实时数据。

每项能力都需要对应的权限，没有权限的能力不会提供给助手，见"智能助手各能力对应的权限"。

## 不能做的事

- 没有执行任意 SQL、任意网络请求或代码的能力，也不能上传文件或联网搜索。
- 不能新增、删除用户，不能重置密码、分配角色、修改菜单或角色权限；这些操作需要到对应的管理页面完成。
- 不能绕过权限、数据范围或审批：这些判断都在服务端完成，与助手怎么回答无关。
- 系统未实现的功能（代码生成、定时任务、服务监控、缓存监控、通知公告管理、Excel 导入导出、头像上传、字典与参数的增删改、注册）助手也无法使用。

## 范围

每个角色有一个数据范围，决定拥有该角色的用户能看到、能操作哪些用户、角色和部门数据。

| 值 | 名称 | 能看到的数据 |
|---|---|---|
| 1 | 全部数据权限 | 全部 |
| 2 | 自定数据权限 | 角色上勾选的部门 |
| 3 | 本部门数据权限 | 用户所在部门 |
| 4 | 本部门及以下数据权限 | 用户所在部门及其下级部门 |
| 5 | 仅本人数据权限 | 只有自己 |

超级管理员不受数据权限限制。数据权限既作用于列表查询，也作用于按 ID 的修改、删除等操作：
列表里看不到的数据，直接调接口也操作不了。
